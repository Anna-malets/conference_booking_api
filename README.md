Conference Room Booking API

1. Опис

API для управління конференц-залами, бронюваннями та аналітикою.

Дозволяє клієнтам:

- Додавати, редагувати та видаляти конференц-зали.

- Шукати доступні зали за датою, часом та місткістю.

- Бронювати зал з урахуванням додаткових послуг.

- Автоматично розраховувати вартість оренди залежно від часу доби.

- Отримувати бізнес-звіти (популярні зали, послуги, дохід по місяцях).

2. Бізнес-завдання

- Надати клієнтам можливість бронювати конференц-зали онлайн.

- Автоматично розраховувати вартість оренди з урахуванням часу та додаткових послуг.

- Забезпечити масштабованість і безпеку для майбутнього розширення.

- Додати аналітику для бізнесу (які зали бронюють найчастіше, які послуги користуються попитом, доходи по місяцях).

3. Технічне рішення

- FastAPI — швидкий та масштабований REST API.

- Pydantic — валідація даних.

- Модульна структура — легке розширення.

- Swagger/OpenAPI — автоматична документація доступна за /docs.

- JWT (можна додати) — для авторизації та безпеки.

- Звіти та аналітика — для бізнесу.

4. Запуск проєкту

4.1. Клонування репозиторію

bash
git clone https://github.com/yourusername/conference_booking_api.git
cd conference_booking_api

4.2. Створення віртуального середовища

bash
python -m venv venv
source venv/bin/activate   # Linux/Mac
venv\Scripts\activate      # Windows

4.3. Встановлення залежностей

bash
pip install -r requirements.txt
У requirements.txt повинно бути:

Код
fastapi
uvicorn
pydantic

4.4. Запуск сервера

bash
uvicorn main:app --reload
API буде доступне за адресою:

Код
http://127.0.0.1:8000
Swagger UI:

Код
http://127.0.0.1:8000/docs

5. Приклади запитів
   
5.1 Додати зал

json
POST /rooms
{
  "name": "Зал А",
  "capacity": 50,
  "base_price": 2000,
  "services": [{"name":"Проєктор","price":500}]
}

5.2 Забронювати зал

json
POST /bookings
{
  "room_id": 1,
  "date": "2024-09-01",
  "start_time": "10:00",
  "end_time": "14:00",
  "services": [{"name":"Wi-Fi","price":300}]
}

5.3 Звіти

json
GET /reports/popular-rooms
[
  {"room_id": 1, "bookings": 5},
  {"room_id": 2, "bookings": 3}
]

GET /reports/popular-services
[
  {"service": "Wi-Fi", "count": 4},
  {"service": "Проєктор", "count": 2}
]

GET /reports/monthly-revenue
[
  {"month": "2024-09", "revenue": 15000},
  {"month": "2024-10", "revenue": 22000}
]

6. Аналітика
   
- Популярні зали — які бронюють найчастіше.

- Популярні послуги — які замовляють найбільше.

- Дохід по місяцях — допомагає планувати бізнес.
